Entry for the [make.fun bounty "The Dog Reviews the Mailman"](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85): one funny one-line review a dog gives the mailman, under 200 characters.

## The review

> One star. He brings me a new box every week, then ruins it by filling it with paper. The box was perfect. He is not.

116 characters. The dog's grievance is simple: the box was perfect, the mailman ruined it with paper.

## How it works

`main.ts` is a deterministic program — no network, no randomness, no secrets, no input. It writes the review above to `/output/entry.txt` (exactly 116 characters, no trailing newline).

```sh
node main.ts
```
